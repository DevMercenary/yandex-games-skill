# Яндекс Игры: сборка, интеграция SDK, модерация

Платформа принимает **статический HTML5-билд** (ZIP, `index.html` в корне, ≤ 100 МБ), подключает свой SDK через `/sdk.js` и вручную проверяет игру по «Требованиям к игре» (модерация 3–5 рабочих дней, повторная отправка — с удваивающимся кулдауном). 90% отказов — одни и те же 12 причин; этот скилл закрывает их на этапе разработки, а не после отказа.

Справочники в `references/` (читай по мере надобности, не все сразу):

| Файл | Когда читать |
|---|---|
| `references/sdk-api.md` | любой вызов `ysdk.*`: точные сигнатуры, лимиты, callback-и, коды ошибок |
| `references/requirements-list.md` | полный нумерованный список «Требований к игре» (1.x–8.x) — чтобы ссылаться на пункты и ничего не пропустить |
| `references/requirements-details.md` | что именно проверяет модератор по пунктам (звук, плеер, сохранения, реклама, ТВ, язык, промо) |
| `references/console-publishing.md` | аккаунт, договор, поля черновика с лимитами, модерация, обновления, языки/домены, покупки в Консоли |
| `references/testing-debug.md` | sdk-dev-proxy (dev/prod), режим черновика, debug-панель, Performance |
| `references/engine-unity.md`, `engine-cocos.md`, `engine-construct3.md`, `engine-defold.md` | игра на движке — читай свой файл целиком перед интеграцией |
| `references/liveops-analytics.md` | после публикации: метрики, Метрика, A/B, флаги, эксперименты, продвижение, промоакции |

Готовые файлы в `assets/`: `index.html` (CSS и порядок загрузки под требования), `yg.js` (обёртка SDK с паузой/рекламой/сохранениями/покупками), `audio.js` (Web Audio вместо `<audio>`). `scripts/check_build.py` — проверка билда и упаковка в ZIP.

## Невозможно опубликовать без этого (проверяется каждый раз)

1. **SDK подключён через `<script src="/sdk.js">`** (относительный путь; файл в архив не кладут; абсолютный `https://sdk.games.s3.yandex.net/sdk.js` — только для игры на своём домене). `YaGames.init()` вызывается после загрузки скрипта, один раз. На debug-панели лоадер должен показывать `IT`.
2. **`ysdk.features.LoadingAPI.ready()`** вызван в момент реальной готовности (появилось меню / «нажми, чтобы начать» / первый попап / кат-сцена), не по таймеру. Лимит ожидания — 90 с.
3. **Язык берётся из `ysdk.environment.i18n.lang` на старте**, даже если язык один. Фолбэк: `ru` для `be, kk, uk, uz`, иначе `en`. Ручной переключатель — только в дополнение.
4. **Пауза по событиям платформы**: `ysdk.on('game_api_pause', …)` — стоп звука и геймплея; `ysdk.on('game_api_resume', …)` — возобновление. Это закрывает «звук при потере фокуса» (1.3), «звук при рекламе» (4.7) и стартовую рекламу, которую платформа показывает сама без callback-ов.
5. **Звук только через Web Audio API.** `<audio>`, `<video>`, `new Audio()` поднимают системный плеер браузера → отказ по 1.6.1.6 / 1.6.2.5.
6. **Прогресс сохраняется сразу после действия игрока** (не по таймеру), для гостя тоже, переживает F5 и поворот экрана. Облако — `player.setData()/setStats()` (+ галочка «Игра использует облачные сохранения» в черновике); `localStorage` допустим только без инап-покупок.
7. **Реклама только через SDK и только в логической паузе**, ≤ 2 с после действия игрока, никакого `setInterval`. Пошаговые/merge-игры — сразу после хода без предупреждения; реалтайм с уровнями < 5 мин — только вне уровня; > 5 мин — по таймеру с предупреждением «Реклама через 2, 1» и паузой игры. Награда за rewarded — только в `onRewarded`, и только бонус, не условие продолжения.
8. **Монетизация есть** (реклама или покупки). Если осознанно нет — напиши это в «Комментарии разработчика».
9. **Покупки**: `getPurchases()` + `consumePurchase()` на каждом запуске (сначала начислить, потом консумировать); название и иконка валюты — из `IProduct` (`priceCurrencyCode`, `getPriceCurrencyImage()`); прогресс в облаке; список товаров совпадает с Консолью.
10. **Отображение**: нет выделения текста и контекстного меню (`user-select:none`, `oncontextmenu="return false"`, `-webkit-touch-callout:none`), нет браузерного скролла и swipe-to-refresh (`overflow:hidden; overscroll-behavior:none; touch-action:none`, viewport `maximum-scale=1`), элементы не обрезаются при ресайзе окна ±20% и повороте; на десктопе активное поле тянется до края (с учётом стики-баннера) и не длиннее 2:1.
11. **Никаких внешних ссылок, YouTube, абсолютных URL на S3, следов «demo/beta/в разработке», интерактивного ИИ.** Ссылки на свои игры — только `ysdk.features.GamesAPI`.
12. **Архив**: один `index.html` в корне, ≤ 100 МБ распакованный, без пробелов и кириллицы в именах файлов и папок. Внешние хосты — через вкладку CSP в Консоли (только https/wss, без путей/портов/IP).

## Рабочий процесс

### 1. Собери структуру билда

```
build/
  index.html      ← в корне; из assets/index.html
  yg.js, audio.js ← из assets/
  game.js, img/, snd/  (имена ASCII, без пробелов)
```

Для движков — экспорт WebGL/HTML5 в такую же плоскую папку (`references/engine-*.md`: шаблоны, настройки сжатия, где плагин). Не копируй `sdk.js`. Относительные пути к ассетам.

### 2. Интегрируй SDK в правильном порядке

```javascript
async function initSDK() {                                     // onload у <script async src="/sdk.js">
    const { lang } = await YG.init({ supportedLangs: ['ru', 'en'],
        onPause: () => Game.pause(), onResume: () => Game.resume() });
    Game.setLanguage(lang);                                    // до первого экрана
    const saved = await YG.load();                             // облако → localStorage
    await Game.boot(saved);                                    // ассеты, первый экран
    YG.ready();                                                // Game Ready
    await YG.consumePending(Game.applyProduct);                // если есть покупки
}
```

Порядок: `init` → язык → загрузить сохранение → загрузить ассеты → `ready()` → остальное. `Game.pause()` обязан останавливать `GameAudio.pause()` и игровой цикл; `resume()` — наоборот. `YG.gameplayStart()` при старте уровня/закрытии меню, `YG.gameplayStop()` при проигрыше/меню/рекламе (индикатор 🎮 на debug-панели должен переключаться). `YG.showInterstitial()` / `YG.showRewarded()` сами ставят паузу и резюмят в `onClose`; вызывай после действия игрока (кнопка «Дальше», «Заново», «Магазин»).

Полные сигнатуры, лимиты (`setData` 100/5 мин, 200 КБ; `setStats` 60/мин, 10 КБ; `getPlayer` 20/5 мин; `setScore` 1/с), лидерборды, флаги, ТВ-события, мультиплеер — `references/sdk-api.md`.

### 3. Запусти локально с настоящим SDK

```bash
npx @yandex-games/sdk-dev-proxy -p ./build --dev-mode=true
```

Dev-режим: моки SDK, реклама-заглушка с теми же callback-ами, сохранения в `localStorage`, каталог покупок из `purchases-catalog.json` в корне проекта, параметры `?mocks={"isAuthorized":true,"lockedOrientation":"portrait"}`. Без регистрации.

```bash
npx @yandex-games/sdk-dev-proxy -p ./build --app-id=<ID черновика>
```

Prod-режим: игра открывается на yandex.ru/games с реальной рекламой, авторизацией, облаком. Нужен черновик в Консоли. `-h http://localhost:3000` вместо `-p` — проксирование до dev-сервера; `--port` (8080), `--csp`, `--tld com`. Добавь `&debug-mode=16` — debug-панель: лоадер `IT`, Game Ready зелёный ≤ 90 с, 文 зелёный на старте, 🎮 переключается, ▶️/⏸️ эмулирует `game_api_pause/resume`, SDK mocks ⚒️ — смена языка, Currency mock (`TST`/¥), Game links mock, ☁️ сброс облака, 🐢 плохая сеть. Подробно — `references/testing-debug.md`.

Проверь руками: F5 посреди игры (прогресс цел), переключение вкладки (тишина ≤ 2 с), сворачивание, поворот, ресайз окна, правый клик/лонгтап, консоль без ошибок, стартовая реклама не ломает звук.

### 4. Проверь и упакуй

```bash
python scripts/check_build.py ./build --zip game.zip
```

Скрипт валит сборку при отсутствии `index.html`, `/sdk.js`, `YaGames.init`, `LoadingAPI.ready`, `i18n.lang`, при пробелах/кириллице в именах, > 100 МБ, YouTube, `setInterval(showFullscreenAdv)`, rewarded без `onRewarded`; предупреждает про `<audio>`, внешние ссылки, `localStorage` без облака. `--selftest` проверяет сам скрипт.

### 5. Заполни черновик в Консоли

Лимиты, которые нельзя угадать (полный список — `references/console-publishing.md` §4):

| Поле | Требование |
|---|---|
| Название | ≤ 50 символов, с заглавной, без капса и слов free/top/best/бесплатно; уникально в каталоге; **байт-в-байт одинаково** в игре, обложке, промо на каждом языке |
| Об игре / Как играть | 100–1000 символов каждое; «Как играть» описывает всё управление |
| Короткое описание | ≤ 70; Описание для SEO 50–160; Ключевые слова ≤ 100 символов, нижний регистр через запятую |
| Категории ≤ 2, Теги ≤ 20, Возрастной рейтинг, Ориентация, Платформы (Десктоп / Мобильные iOS+Android / ТВ) | обязательны; «Игра переведена на» — только реально переведённые языки, модерация проверит каждый |
| Иконка 512×512 PNG; Обложка 800×470 PNG; Обложка на витрину 1560×520 PNG/JPG | не скриншоты, без рамок/скруглений/текста статус-бара/бейджей |
| Скриншоты | 16:9 (десктоп, альбом) или 9:16 (портрет), 1280–2560 px по длинной стороне, JPEG/24-бит PNG, ≥ 2 на каждую выбранную платформу, геймплей ≥ 70% кадра |
| Горизонтальное видео (обязательно) | 16:9 MP4, высота ≥ 400, ≤ 28 с, ≤ 100 МБ; вертикальное 9:16 — опционально |
| Облачные сохранения | галочка, если используешь `setData/setStats` |
| Комментарий разработчика (≤ 2048) | нестандартная механика сохранения, отсутствие монетизации, тестовые логины |

Покупки подключай **до** отправки (Профиль → ЕЛС «Активен», иначе кнопка «Перейти к ЕЛС» или письмо на games-partners@yandex-team.ru с ID игры). Товары: вкладка Инап-покупки (иконка 256×256 PNG, описание ≤ 200). Тестовые логины — там же → Настройки; тестируй покупки только когда консумирование уже работает.

### 6. Модерация

Одновременно ≤ 2 новых игры (новый аккаунт — 1), обновления не ограничены. Полная проверка 3–5 рабочих дней плюс очередь; после отказа кулдаун 24 ч → 2 → 4 → 8 → 16 дней (сброс раз в 28 дней). Отозвать можно в течение 2 ч. Рейтинг ≤ 30 три недели после формирования → снятие с публикации. Причины отказа приходят на почту Яндекс ID с номерами пунктов — исправляй **все** сразу, не по одному.

## Типовые ошибки агента

| Ошибка | Правильно |
|---|---|
| `<script src="https://yandex.ru/games/sdk/v2">` или скачанный `sdk.js` в архиве | `<script src="/sdk.js">`, файл не включать |
| `ready()` сразу после `init()` или по `setTimeout` | после загрузки ассетов, когда виден интерактивный первый экран |
| `visibilitychange` вместо `game_api_pause` | события SDK (они же приходят при рекламе и покупках); `visibilitychange` — только как дополнение |
| `navigator.language` для локализации | `ysdk.environment.i18n.lang` |
| `<audio loop>` для музыки | `AudioContext` + `decodeAudioData` + `AudioBufferSourceNode`; пауза через `ctx.suspend()` |
| награда в `onClose` rewarded | только в `onRewarded`; `onClose` — возобновить игру |
| реклама при старте уровня по таймеру в реалтайм-игре с короткими уровнями | между уровнями по кнопке игрока; стартовую рекламу платформа показывает сама |
| `consumePurchase` до начисления | начислить (`setData/incrementStats`) → консумировать |
| `ysdk.getLeaderboards()`, `player.getID()`, `getMode()` | `ysdk.leaderboards.*`, `player.getUniqueID()`, `player.isAuthorized()` |
| ссылка «Другие игры» на yandex.ru/games/developer/… | `ysdk.features.GamesAPI.getAllGames()` |
| `score` в лидерборд типа `time` в секундах | миллисекунды |
| Unity: ищешь «официальный пакет Яндекса» | его нет — Яндекс документирует Plugin Your Games 2.0 (`YG2`); настройки билда и API в `references/engine-unity.md` |

## Если игра на движке

Прочитай целиком свой `references/engine-*.md` **до** правок: там точные имена плагина и методов (Unity — официальные страницы Яндекса ведут на сторонний Plugin Your Games 2.0 с классом `YG2`, свой WebGL-шаблон и настройки сжатия; Construct 3 — аддон `YandexGamesSDK` с действиями/условиями; Defold — расширение `ysdk.*` в snake_case; Cocos Creator — расширение, генерация шаблонов и `import { ysdk } from 'db://yandex-games-sdk/ysdk'`). Общие требования (пункты выше) действуют для всех движков; `check_build.py` запускай на экспортированной папке.
