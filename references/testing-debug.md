## 1. Способы тестирования

| Способ | Когда подходит | Где файлы игры | Взаимодействие с платформой |
|---|---|---|---|
| Dev-окружение (локально, моки SDK) | Активная разработка и отладка игровой логики | Локально | Нет |
| Prod-окружение (локально, реальный SDK) | Финальная проверка перед отправкой на модерацию | Локально | Да |
| Режим черновика | Финальная проверка перед отправкой на модерацию | На сервере Яндекса | Да |

Инструменты отладки: **debug-панель** (проверка выполнения требований к SDK) и **Performance в DevTools** (метрики Game Ready и Time To Interactive). После публикации в игру можно заходить как обычный игрок.

## 2. Чеклист самопроверки

Перед отправкой на модерацию (возможна только после заключения договора):

1. Протестировать черновик с debug-панелью — все индикаторы в правильном состоянии (см. раздел 5):
   - лоадер `IT` (не `IF`);
   - Game Ready зелёный (`ready` вызван, не по таймауту 90 с);
   - `文` — **I18N is used**;
   - геймпад 🎮 переключается (используются `GameplayAPI.start()/stop()`);
   - валюта меняется при **Currency mock is enabled** (если есть покупки);
   - ссылки на другие игры открывают статическую страницу при **Game links mock is enabled** (если есть такие ссылки).
2. Проверить игру в разных ОС и браузерах и на всех платформах, указанных в поле **Поддерживаемые платформы** (ПК, телефоны, ТВ — у ТВ особые требования).
3. Протестировать в режиме черновика глазами пользователя.
4. Если есть покупки — протестировать под логином из **Список логинов для тестовых покупок** (плата не взимается). Консумирование (проверка необработанных платежей) должно быть настроено до тестов.
5. Пройтись по частым причинам отказа:

| Пункт | Нарушение | Что проверить |
|---|---|---|
| 1.6.1.8, 1.6.2.7 | Контекстное меню браузера | Правый клик / долгое нажатие в игровой области не открывает системное меню |
| 1.6.1.6, 1.6.2.5 | Системный плеер | Аудио/видео играет во встроенном игровом плеере, не в системном |
| 4.7 | Звук при рекламе | Звук игры на паузе во время показа рекламы |
| 1.3 | Звук при уходе со вкладки | Звук останавливается при потере фокуса страницы (проверяется кнопкой 👁 в debug-панели) |
| 2.14 | Автоопределение языка | Язык берётся из `ysdk.environment.i18n.lang`; переключение через **SDK mocks** меняет язык игры |
| 1.19.2 | Game Ready | `LoadingAPI.ready()` вызывается после загрузки |
| 1.1 | SDK | Скрипт `/sdk.js` подключён из официального источника до `YaGames.init()`, без ошибок |
| 1.9 | Сохранение прогресса | Результаты/уровни/настройки сохраняются между сессиями |
| 1.14 | Запуск и JS-ошибки | Загрузка не зависает; в консоли нет ошибок на старте и в процессе |
| 1.15 | Незавершённый вид | Нет плейсхолдеров, «demo», «в разработке», «trial version» |
| 2.3 | Жанр | Геймплей соответствует выбранной категории |
| 8.2.2 | Название | Нет «free», «top», «best», «бесплатно», «бесплатный» |
| 1.6.1.7 | WebGL | Если WebGL недоступен — никаких уведомлений об этом при открытии |

Проверка во всех браузерах и ОС силами Яндекса происходит только на модерации (в порядке очереди); при проблеме в одном из браузеров/ОС из требований игру отклонят, причины придут на почту Яндекс ID.

## 3. Режим черновика

Требуются регистрация в Консоли и созданный черновик игры. Игра взаимодействует с реальной платформой:

- Открывается по реальному адресу на yandex.ru/games.
- Запросы на внешние хосты — только если хосты добавлены на вкладке **CSP**.
- Показывается настоящая реклама (до публикации — тестовые рекламные блоки Яндекса; из-за ограничений хостинга реклама локально может не показываться, но учёт показов идёт сразу).
- Игрок авторизуется через Яндекс Паспорт.
- Данные игрока и лидерборды сохраняются на сервере.
- Каталог товаров — с сервера, покупки обрабатываются на сервере (тестовые логины — без оплаты).
- Debug-панель — параметр адресной строки `&debug-mode=16`.

**Открыть черновик:**
1. Консоль → **Игры** (https://games.yandex.ru/console/applications) → нажать игру.
2. Открыть черновик: впервые — **Создать черновик**; есть — откроется сам; несколько неопубликованных версий — выбрать по названию.
3. Проверить, что загружен актуальный архив; если нет — выбрать файл → **Сохранить** → обновить вкладку **Черновик**.
4. В поле **Архив** перейти по ссылке:
   - **Открыть черновик** — как увидят пользователи;
   - **Открыть черновик с debug-панелью** — для тестирования сценариев.

Открыть игру сразу на нужном языке: на вкладке **Черновик** в поле **Игра переведена на** нажать на язык — игра откроется на нём в новой вкладке.

## 4. Запуск с локального сервера

Из локально запущенной игры доступны все функции SDK. Два окружения: prod и dev.

### Prod-окружение

Требуются регистрация и черновик игры. Поведение идентично режиму черновика (реальный адрес yandex.ru/games, CSP, настоящая реклама, Паспорт, серверные данные/покупки, `&debug-mode=16`), но файлы игры отдаются с локального сервера.

**Вариант A. Самостоятельно (без npm):**
1. Поднять сервер на `localhost`.
2. Открыть игру в режиме черновика.
3. Добавить в адрес параметр `?game_url=https://localhost`.

Из соображений безопасности в `game_url` поддерживается только домен `localhost`.

**Вариант B. npm-пакет `@yandex-games/sdk-dev-proxy`** (https://www.npmjs.com/package/@yandex-games/sdk-dev-proxy):

```console
npm install -g @yandex-games/sdk-dev-proxy
```

Запуск — одно из двух:

```console
# проксировать до уже запущенного локального сервера (webpack-dev-server и т. п.)
npx @yandex-games/sdk-dev-proxy -h <Адрес локального сервера>

# раздавать папку с билдом игры
npx @yandex-games/sdk-dev-proxy -p <Путь до папки с игрой>
```

Пакет проксирует запросы к ресурсам SDK на тот же сервер, где будет расположена игра.

С `--app-id` при запуске сразу откроется игра на yandex.ru/games:

```console
npx @yandex-games/sdk-dev-proxy -p <Путь до папки с игрой> --app-id=<ID игры>
```

Без `--app-id` в консоли выводятся шаблонная ссылка на игру на сервисе и ссылка на локальный сервер.

**Параметры запуска:**

| Параметр | Описание |
|---|---|
| `--help` | Справка |
| `--host`, `-h` | Хост, на котором расположен локальный сервер игры (например, для `webpack-dev-server`) |
| `--path`, `-p` | Путь до папки с ресурсами игры (**`-p` — это path, не port**) |
| `--port` | Порт, на котором откроется сервер (по умолчанию `8080`) |
| `--app-id`, `-i` | ID черновика игры |
| `--csp`, `-c` | Добавляет метатег `Content-Security-Policy`, идентичный тому, что сервис создаст в `index.html` |
| `--log`, `-l` | Логирование запросов в консоль (по умолчанию включено) |
| `--tld` | Домен `yandex.tld`, например `com` (по умолчанию `ru`) |
| `--dev-mode` | `true` — dev-окружение; по умолчанию `false` (prod) |

### Dev-окружение

Регистрация и черновик **не требуются**. Связи с платформой нет, все вызовы SDK подменены моками — быстрый цикл «правка → перезагрузка».

- Игра открывается напрямую в `https://localhost`.
- Нет ограничений CSP — любые внешние хосты.
- Вместо рекламы — заглушки; все callback-функции отрабатывают как в prod.
- Авторизация — мок браузерного диалога.
- Данные игрока и лидерборды — в `localStorage`.
- Каталог товаров — из локального файла `purchases-catalog.json`; покупки игрока — в `localStorage`.
- Параметры отладки задаются через адресную строку (`?mocks=...`).
- В консоли браузера автоматически логируются все вызовы SDK с разбивкой по модулям.

Запуск тем же пакетом с `--dev-mode=true`:

```console
npx @yandex-games/sdk-dev-proxy -h <Адрес локального сервера> --dev-mode=true
npx @yandex-games/sdk-dev-proxy -p <Путь до папки с игрой> --dev-mode=true
```

**Параметры адресной строки (`mocks`):**

```ts
export interface SDKMocks {
    /** Разрешено ли добавить ярлык на рабочий стол? */
    canShowPrompt?: boolean;
    /** Авторизован ли игрок? */
    isAuthorized?: boolean;
    /** Если у игры заблокирована ориентация. */
    lockedOrientation?: ELockedOrientation;
}

export enum ELockedOrientation {
    LANDSCAPE = 'landscape', // только альбомная
    NONE = 'none',           // обе ориентации
    PORTRAIT = 'portrait',   // только портретная
}
```

Пример:

```text
localhost:8080?mocks={"canShowPrompt":true,"isAuthorized":true,"lockedOrientation":"landscape"}
```

**Локальный каталог товаров:** создать в корне проекта `purchases-catalog.json` со списком покупок — таким же, как в Консоли (**Инап-покупки** → **Инапы**). SDK в dev-режиме читает каталог из этого файла; при вызове покупки показывается мок-диалог с вариантами «успех» и «отмена».

```json
[
    {
        "description": "Well styled modern avatar image",
        "id": "avatar",
        "imageURI": "{path-to-image}",
        "price": "100 RUB",
        "priceCurrencyCode": "RUB",
        "priceValue": "100",
        "title": "Premium avatar",
        "getPriceCurrencyImage": "return ''"
    }
]
```

(в `getPriceCurrencyImage` вместо `''` можно подставить путь до изображения валюты.)

## 5. Debug-панель

Инструмент тестирования черновика: отслеживание вызовов SDK, эмуляция плохого соединения, снятие фокуса, отключение загрузочного экрана Яндекса и т. д. Появляется в левом нижнем углу страницы игры.

**Включить:**
- Через Консоль: открыть игру → в левом верхнем углу **Открыть с debug-панелью** (или ссылка **Открыть черновик с debug-панелью** в поле **Архив**).
- Через адресную строку: добавить `debug-mode=16`, например `https://yandex.ru/games/app/XXXX?debug-mode=16` (`XXXX` — ID игры). Если параметры уже есть — `&debug-mode=16`.

**Состав панели (слева направо):** `IT` лоадер | 🟢 индикатор Game Ready | ⚒️ SDK mocks | 文 язык | ▶️ Play | 🎮 геймпад | ⏱️ часы.

### Лоадер

| Индикатор | Текст | Значение |
|---|---|---|
| `W` | — | Ожидает инициализации |
| `IT` | Is loader: true | Загрузчик SDK инициализирован верно |
| `IF` | Is loader: false | Используется старый лоадер — подключать SDK по документации (п. 1.19.1) |

### Индикатор Game Ready (🟢)

Навести курсор — показывает статус SDK и момент вызова `LoadingAPI.ready()` (п. 1.19.2).

| Состояние | Текст | Значение |
|---|---|---|
| Мигает фиолетовым | SDK is not initialized. Wait for "unit" call. (текст приведён как в документации) | Игра ожидает инициализации SDK |
| Мигает фиолетовым | The game has initialized the SDK. Waiting for call "ready". | SDK инициализирован, ждём `LoadingAPI.ready()`. Таймаут ожидания — 90 секунд |
| Зелёный | The game called ready after … ms. | `ready()` вызван через указанное число миллисекунд |
| Красный | "ready" called on timeout. | `ready()` не вызван за 90 с — считается, что Game Ready в игре не используется |

Ошибка `SDK is not defined` при «инициализированном» индикаторе: скрипт `/sdk.js` должен быть подключён до выполнения `YaGames.init()`. Индикатор регистрирует только то, что SDK установлен и скрипт подключён.

### Кнопка инструментов SDK mocks (⚒️)

| Инструмент | Как работает |
|---|---|
| **Выбор языка** (выпадающий список, например **En**) | Меняет автоопределяемый язык; игра открывается на нём в новой вкладке. Методика проверки п. 2.14 |
| 🔗 **Game links mock is disabled / enabled** | Проверка п. 8.4.1: в режиме проверки вместо ссылок на другие игры должна открываться статическая страница. Переключить → подождать 5 секунд → перезагрузить игру |
| 👁 **Remove the focus from the game** / 👀 **Return the focus to the game** | Снять/вернуть фокус с игры (проверка паузы звука и геймплея при потере фокуса) |
| 🚀 **Network throttling is disabled** / 🐢 **Network throttling is enabled** | Ракета — стандартное время ожидания ответа сервера. Черепаха — клиент требует ответ сразу; нет ответа за короткое время → считается, что сервер не ответил. Эмуляция плохого соединения, ошибки покупки при таймауте сервера SDK |
| 🪙 **Currency mock is disabled / enabled** | Эмулирует название и иконку портальной валюты. Включить → 5 секунд → перезагрузить → обозначение валюты в игре должно смениться на моковое (модераторы используют текст `TST` и иконку йены ¥). Не сменилось — валюта не берётся из SDK, нарушение п. 1.13.2, отклонят. Вернуть — **disabled** и обновить страницу |
| ☁️ **Clear cloud data** | Вызывает `player.setData()` и `player.setStats()` с пустыми значениями — игра запускается как в первый раз (тест онбординга) |

### Индикатор языка (文)

| Текст | Значение |
|---|---|
| I18N is used | Автоопределение языка через SDK подключено |
| I18N is not used | Не подключено (нарушение п. 2.14) |

### Кнопка Play (▶️)

Индикатор активности игры. Платформа сообщает о паузе/продолжении событиями `game_api_pause` и `game_api_resume`; кнопка имитирует их:
- ▶️ — игра в фокусе, идёт игровой процесс.
- ⏸️ — игра не в фокусе: открыто окно покупок или идёт реклама.

### Кнопка геймпада (🎮)

Эмулирует `GameplayAPI.start()` / `GameplayAPI.stop()` (п. 1.19.3):
- Тёмный фон (по умолчанию) — геймплей не использован в игре.
- Зелёный — геймплей идёт.
- Красный — геймплей на паузе.

### Кнопка часов (⏱️)

Прозрачность загрузочного экрана Яндекса:
- **Mute Game loader** — прозрачность выключена: при старте показывается загрузочный экран с иконкой игры.
- **Show Game loader** — прозрачность включена: иконка прозрачная, видно, что происходит с игрой во время загрузки.

## 6. Performance в DevTools

Платформа отправляет метки **Game Ready** и **Time To Interactive** (TTI) в Performance Timeline:
- **Game Ready** — срабатывает при вызове `ysdk.features.LoadingAPI.ready()`.
- **Time To Interactive** — срабатывает автоматически по условиям Lighthouse.

Посмотреть:
1. Запустить игру любым способом.
2. Открыть DevTools: Windows — **F12** или **Ctrl+Shift+I**; macOS — **Cmd+Opt+I**.
3. Вкладка **Performance**.
4. В левом верхнем углу **Record and reload**, дождаться сборки профиля. В строке **Timings** появятся жёлтые метки **Game Ready** и **Time To Interactive** — видно, какие задачи выполняются до них, чтобы оптимизировать загрузку.

## 7. Частые вопросы

- **Как протестировать покупки?** Авторизоваться под аккаунтом из **Инап-покупки** → **Настройки** → **Список логинов для тестовых покупок** — все платежи будут тестовыми, без оплаты. Работает в режиме черновика и prod-окружении (через несколько минут после добавления логина).
- **Тестирование на ТВ** — возможно; см. требования 1.6.3 (Тестирование игры).
- **Как проверить, что реклама настроена?** Условия: код SDK рекламы в игре; новая версия загружена и прошла модерацию; договор по ЕЛС или подключена монетизация через РСЯ. Тогда для игры автоматически создаётся рекламный блок. Проверить: Консоль → список игр → открыть игру по значку ссылки справа. Локально реклама может не показываться (ограничения хостинга), но учёт показов и переходов идёт сразу. Данные о доходе в **Метрики** → **Метрики монетизации** обновляются с задержкой 2–3 дня; без ЕЛС статистика блоков — в интерфейсе РСЯ.
- **WebGL** — поддерживается, если в браузере включено аппаратное ускорение; заранее протестировать в Яндекс Браузере.
